Model A SAR-derived WFDashed segments interpolate between available SAR observations

The model selector changes graph series only; map content and summary values remain Model A. Prediction metrics use the selected model output. SAR metrics use valid pixels inside each SAR swath. Model A RMW is estimated from 10 km radial bins; Model B and Model C RMW and R64 use approximate grid-resolution radial bins. Post-processing excludes C02-bright daylight artifacts plus one acquisition at each edge for Model A only, applies a centered six-hour median, smoothly interpolates Prediction across the excluded times, and limits charts to three hours beyond the first and last SAR match.
