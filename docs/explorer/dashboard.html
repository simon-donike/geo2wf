The model selector changes graph series only; map content and summary values remain Model A. The IBTrACS maximum sustained wind and classification are included as a reference on the Maximum wind chart. Prediction metrics use the selected model output. SAR metrics use valid pixels inside each SAR swath. Model A RMW is estimated from 10 km radial bins; Model B and Model C RMW and R64 use approximate grid-resolution radial bins. Post-processing excludes C02-bright daylight artifacts plus one acquisition at each edge for Model A only, applies a centered six-hour median, smoothly interpolates Prediction across the excluded times, and limits charts to three hours beyond the first and last SAR match.

About the data

Prediction and observation, together

The red series is derived from the selected graph model; the selector does not change the map or summary cards. The black reference on Maximum wind is the IBTrACS maximum sustained wind, with its classification shown in the hover details. The optional NWP overlay shows each available forecast as a muted gray dashed line. All SAR swaths share a fixed 0–60+ m/s scale. Click a three-hour acquisition dot to show its fixed-scale CMI_C15 image; click it again to hide it. Gray chart dots mark matched SAR fields; dashed lines interpolate visually between those sparse observations.
